## Source-verified scientific definitions; unchanged

F.3 constructs relative detector response `r_j` on the accepted `hgcer3` coordinates using positive-response pion training (`0<NPE<=2` weak-positive vs `NPE>2` control); it is **not** absolute pion-to-kaon leakage probability. F.4 forms within each canonical-`t` parent:

```text
b_j       = s_j * w0_j
B         = sum_j b_j
U         = sum_j b_j * r_j
N_signed  = U/B
C_j       = r_j/N_signed
b_rw,j    = s_j * w0_j * C_j
sum_j b_rw,j = B
```

`w0` already owns the baseline pion-control to kaon-background transfer; `C` is its parent-normalized relative refinement. `r` is independently fitted; `C` is *not* independent of `w0` and the signed source measure. The current private F.6.3 `YA/MM_A` already represents the baseline pion background reweighted with `w0*C`, **not** an independently produced Method-A-only final kaon yield/MM. Distinguish background contributions (`b`, `b_rw`) from final extracted kaon yields (`Y0`, `YA`). All existing cuts, selections and correction formulas remain unchanged.
