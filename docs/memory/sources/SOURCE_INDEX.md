# KaonLT source and evidence index

## Authority and role

For implementation, current source and an exact newer diff outrank history
and inference. For runtime, fresh farm evidence and accepted canonical
evidence outrank source review. Git subjects, local tests, and collectors
alone never establish runtime validation.

`CURRENT.md` is the sole ordinary active-state authority. The handoff is
exceptional-transfer-only and cannot override CURRENT. Evidence, phase, and
decision records own runtime facts, implementation chronology, and durable
contracts respectively. This index is provenance/navigation, not active status.
