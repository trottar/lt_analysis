# KaonLT ChatGPT Project-History Import

This directory is a one-time historical import package for the KaonLT durable-memory system.

Copy the directory into:

```text
docs/memory/import/chatgpt_project_history_2026-09-11/
```

Then start a **new Codex chat** in the same VS Code KaonLT workspace and give it `CODEX_MIGRATION_CONTRACT.md`.

The repository already has the active-memory layer (`AGENTS.md`, `CURRENT.md`, `MEMORY.md`, the current handoff, and roadmap). This package supplies the deeper history that the initial conservative bootstrap intentionally did not infer.

This is not a verbatim transcript dump. It is a structured reconstruction of the recoverable scientific/development history from project chats, authoritative handoffs, Codex plans, Git/source lineage, supplied farm-validation results, analysis procedure notes, and relevant theses. Gaps are explicit in `KNOWN_GAPS.md`.

Do not modify production source while importing this package.
